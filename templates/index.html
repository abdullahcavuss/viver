If you give a folder, VIVER finds the changes by itself and you commit with one click. If you leave it empty, you commit by uploading a folder/ZIP from the browser.
How does it work?
  1. Work in LabVIEW and save.
  2. On the Changes tab, see the changed VIs, write a message and commit. The project is backed up instantly.
  3. Pick any two versions in History and inspect the VI differences on the block diagram.
  4. Download any version as a ZIP or restore it into the project folder.
